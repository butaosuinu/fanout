fanout fans a GitHub parent issue's OPEN sub-issues out into one tmux pane per child — each with its own git worktree and an agent CLI launched with a per-issue briefing. These pages cover the full surface: installing, the first fan-out, the wave-driven workflow, monitoring, every flag, settings, agent integrations and troubleshooting.
